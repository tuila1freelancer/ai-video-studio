# Implementation Prompt — AI Video Studio: Natural Narration + Smooth Voice-Synced Motion + One-Shot Publish-Ready

## 1. MISSION

Turn this pipeline into a product where a non-expert owner types a topic, clicks generate, and gets a video that is **publish-ready on the first run** — narration that sounds like a knowledgeable human sharing something genuinely useful (not an engagement-bait template), graphics that are beautiful and glued to the voice with no kinks or rushed pops, and a finish that either **is** premium on every scene or **auto-heals itself until it is**. The owner must never scrub 12 scenes hunting for the weak two. **Definition of done:** open the output, watch once, publish immediately — zero manual correction, and if anything could not be auto-fixed the system tells you *exactly which scene and why* instead of shipping it silently as "green."

This session already upgraded the visual codegen prompt (bespoke hero constructions, motion signatures, auto-contrast). **Do not re-touch those.** The new work is: (A) SCRIPT QUALITY — kill formulaic filler, make narration valuable and human; (B) PUBLISH-READINESS — a closed-loop self-healing pipeline with a real final QC gate; (C) ANIMATION SMOOTHNESS. All work happens on `main`, in English, inside the deterministic HyperFrame render path, degrading gracefully offline.

## 2. ROOT CAUSES TO FIX (verified, with evidence)

### Theme A — Script quality (formulaic filler)
- **A1 (CRITICAL).** The single-call short-form prompt hard-mandates a closing micro-hook on *every* scene, listing "a short question" first. Combined with the `mình / các bạn` persona (`llm.js:342`), the model emits a viewer-addressed tag-question every scene. → `src/providers/llm.js:338` ("*The LAST sentence of each scene is a MICRO-HOOK … (a short question, a tease, "but…"…)*"). Symptom: `CÒN BẠN?`, `MUỐN THỬ?`, `ĐỒNG Ý CHỨ?`, `BẠN TIN KHÔNG?` on scene after scene.
- **A2 (HIGH).** Two *more* forced questions stack on top: a mid-video pattern-interrupt and a final comment-bait question. → `llm.js:339`, `llm.js:341`; mirrored in the two-stage path `llm.js:430`.
- **A3 (HIGH).** Fabricated statistics: the "SPECIFIC numbers" rule seeds literal example figures with no grounding requirement, and the model copies the placeholder verbatim (`87%` → narration `tăng 87% độ chính xác`). → `llm.js:340`. Compounded by the keyword rule that pushes a punchy number into every scene as emphasis bait → `llm.js:343`.
- **A4 (MEDIUM).** Scene 1 is forced into clickbait: PAIN→PROMISE + "OPEN A LOOP" with a mandatory number/timeframe → `llm.js:337` (symptom: `tăng 10 lần hiệu quả` + vague "hidden button" tease).
- **A5 (correction — do not "add a first-ever anti-filler line").** An anti-filler clause already exists but is mis-targeted at discourse markers ("as I said before"), not tag-questions → `llm.js:246`. **Broaden** it, don't pretend it's absent.

### Theme B — Value density
- **B1 (CRITICAL).** No substance/insight/credibility bar exists anywhere. The scorer checks only mechanics (empty / lang-leak / truncated / under-budget / over-budget / 5-gram repetition) → `src/content/scorer.js:39-68`; editorial only rewrites what the scorer flags → `src/pipeline/stages/editorial.js:39`. A well-formed vapid scene ("*Mình luôn yêu cầu đóng vai chuyên gia, CÒN BẠN?*") passes every gate.
- **B2 (HIGH).** The "concrete example / mechanism" instruction exists **only** on the two-stage path (`llm.js:452`) and the under-budget enrich (`budget.js:118`); the short-form single-call path — which built the offending video — never asks for a demonstrable example. The thinnest-instruction path builds the shortest videos.
- **B3 (MEDIUM).** Device-monotony is structurally undetectable: the repetition check uses n=5 grams with a `<3`-gram skip → `scorer.js:14,61`, so 2–3-token tag-questions produce zero grams and N near-identical questions are invisible.
- **B4 (correction).** The self-heal levers that *do* touch thin scenes optimize **word count, not value**: editorial under-budget "write it UP to ~N words" (`editorial.js:52`) and budget enrich "add … to ~N words" (`budget.js:118`) — catching a thin scene just makes it *longer*, still vapid.

### Theme C — Duration / budget tyranny
- **C1 (CRITICAL, same code as A1).** A ~26–27-word/scene cap (`wordsForSlot` → `llm.js:236-240`; band "NO more" → `llm.js:246`) plus the mandatory hook leaves no room for substance — the question dominates the slot.
- **C2 (HIGH).** Scene count is a hard mechanical division `Math.round(videoDuration/sceneDuration)` → `llm.js:279`, threatened as "EXACTLY N scenes … a FAILED script" → `llm.js:335`. **Correction:** the *gate* is asymmetric — `minScenes = ceil(sceneCount*0.7)` (`llm.js:348`) enforces only a **lower** floor; there is no upper cap. So merging *down* to fewer breathing beats is what's actually blocked; exactness is only prompt-threatened.
- **C3 (HIGH).** One uniform word budget everywhere, no scene-role concept; the tight prompt band is the real uniformity driver (not editorial/scorer, whose thresholds are wide). Reuse: `llm.js:282`, `budget.js:38,51`, `editorial.js:38`, `scorer.js:37`.
- **C4 (MEDIUM).** Threat framing ("FAILED script", "NO more", "never overflowing") biases the model toward safe generic filler → `llm.js:335`, `llm.js:246`.
- **C5 (missed).** `scriptBudgetOk` (`llm.js:254-260`) only re-asks on gross **overrun** (mean > 1.5× target), never on **thinness**; after 3 attempts `generateScript` dumps the LLM's richer reply for the bland deterministic `offlineScript` (`llm.js:359-364`) — a length gate that destroys value at generation and fights any "extended example" beat.
- **C6 (missed).** The tyranny is **replicated in the long-video path**: `twoStageScript` issues "EXACTLY perCh elements (fewer fails)" per chapter → `llm.js:453`, `perCh` at `llm.js:436`. Fixing only <180s leaves every long video grid-locked.

### Theme D — Downstream trim protects the filler (self-heal fights itself)

## 4. ACCEPTANCE CRITERIA (measurable)

**Script**
- No scene voice ends with an empty viewer-addressed tag-question; the named offenders (`còn bạn?`, `muốn thử?`, `đồng ý chứ?`, `tuyệt vời chứ?`, `bạn tin không?`, `bạn sẵn sàng chưa?`) appear **zero** times across a 20-topic sample.
- **≤1** viewer-directed question in the entire video; never two consecutive scenes ending in `?`.
- Every scene narration is a self-contained, specific, valuable thought — an LLM-judge specificity/value score ≥ threshold on ≥95% of scenes; each numeric claim is traceable to the source (no placeholder `87%`/`10 lần` leakage).
- The single-call and two-stage paths behave identically on the above.
- On over-length videos, the trim keeps the substantive clause and drops any tag-question (both LLM and deterministic passes).

**Scene & on-screen integrity**
- No on-screen label is stopword-led, mid-phrase-truncated, or a mid-clause prefix of a narration sentence (all label paths).
- No scene voice ends mid-thought (LLM and offline).

**Animation**
- Shortest real entrance ≥ ~0.4s regardless of `tplScale`/warp; no sub-0.35s "flash" pops.
- No velocity kink at beat knots for continuous motions (monotone-cubic map); `whipOut`/`beamSweep` show blur/interpolation, not discrete jumps.
- Beat graphics land on the spoken word (karaoke agreement); flat-ratio fallback used only when genuinely no anchors survive.
- No focal element frozen for the final ≥0.4s (frozen-tail probe green); P12 `FROZEN_TAIL`/`SUBTITLE_COLLISION` still enforced.

**Publish-readiness**
- **0 plain-template fallbacks in a normal (Chrome-available, LLM-on) run** — or every such scene is auto-regenerated to bespoke/premium before done.
- Every scene carries a persisted `tier`; any non-bespoke scene is surfaced (indices + reason) in `qc_report.json` and over WS, ranked in the review gate.
- Final automated QC (script + per-scene visual + audio + subtitle sync) is **green before status=done**; a Chrome-less run reports `visualQc:'skipped'` / "unverified," never a false green.
- Determinism preserved: identical `srt_json` + seed ⇒ identical page (P12, `PSNR_OK=70`).
